# 07 / M5：编辑几何接管

## 目标

Rust 接管局部橡皮擦、自由套索和选区移动，并保证每个手势是一个可撤销事务。重点是连续几何语义和编辑后性能不退化。

## 顺序

1. 整笔擦除保持稳定，作为空间索引与事务基线。
2. 局部擦除：broad phase 查询候选 → swept capsule 与线段求交 → 插值切点 → 生成片段。
3. 套索：简化套索路径 → AABB broad phase → polygon/segment narrow phase → 返回 ElementId。
4. 移动：前端临时 transform preview → 抬手一次提交 TranslateSelection → 一次更新 R-tree 与 DB。
5. 每个操作建立逆命令和随机属性测试。

## 局部擦除语义

现有 Butterfly 是按离散点删除，快速笔画时可能擦不断。目标语义是橡皮轨迹扫过的 capsule 与笔画中心线/轮廓连续相交。切点必须插值 pressure 和 elapsed time，不可简单丢掉整段采样。

## 套索语义

V1 固定一种规则并写入测试：建议“笔画中心线任一线段与套索内部或边界相交即选中”。不要在 UI 中根据元素类型使用隐藏的不同规则。

## 移动语义

拖动过程中不逐帧写 SQLite、不逐帧重建所有路径。预览只施加临时矩阵；结束时生成一个事务，更新元素坐标/bounds、内存 R-tree 和 dirty bounds。

## 退出门槛

- [ ] 快速长线可被连续擦断；
- [ ] 切点属性插值正确；
- [ ] 套索只返回 ID；
- [ ] 移动 500 条笔画只产生一个历史项；
- [ ] 擦除/套索/移动后继续写字无持续退化；
- [ ] 10,000 随机几何测试无不变量破坏。
