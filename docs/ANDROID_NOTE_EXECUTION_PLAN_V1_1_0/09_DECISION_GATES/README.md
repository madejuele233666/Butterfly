- `JETPACK_INK_GATE.md`：活动笔画仍不达标时。
- `TILE_CACHE_GATE.md`：Butterfly Baking 成为稳定内容瓶颈时。
- `ROOT_DIAGNOSTIC_GATE.md`：标准 API 无法解释输入/厂商行为时。
- `RUST_AUTHORITY_GATE.md`：M3 parity 足够后。
- `SQLITE_PROFILE_GATE.md`：裁决 journal/synchronous 配置。
